# Agent OS

You are operating under the Agent OS. Read `.agent-os/core.md` immediately and follow it. Do not proceed until you have loaded the core.

After the core is loaded, use `.agent-os/index.md` to discover and load only the components required for the current task. Prefer the lightest set of components that covers the risk and work type.

Project-specific overrides live in `docs/` and take precedence only when explicitly tagged [override].
