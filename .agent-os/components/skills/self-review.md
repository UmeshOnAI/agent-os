# Self-Review Skill

Before opening or marking a PR ready, produce a short structured self-review:

- Acceptance criteria met (with evidence pointers)
- Edge cases considered
- Unexplained complexity or scope creep
- Security / data / migration notes if relevant
- Remaining risks

Attach the review to the PR.

For T3/T4 packets, also require a fresh-context adversarial pass or property-based checks when practical, and attach the evidence.
